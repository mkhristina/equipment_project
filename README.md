# Equipment Management System

## Описание проекта

Equipment Management System — система учёта производственного оборудования и управления заявками на техническое обслуживание.

Проект разработан на Python и предназначен для хранения информации об оборудовании, обработки заявок на ремонт и формирования отчётов.

## Используемые технологии

- Python
- Object-Oriented Programming (OOP)
- JSON
- HTML Parsing
- SQLite
- SQL
- Git

## Структура проекта

| Файл | Описание |
|---|---|
| `models.py` | Модели и классы оборудования |
| `maintenance_request.py` | Класс заявок на техническое обслуживание |
| `service.py` | Логика управления заявками |
| `equipment.json` | Данные об оборудовании в формате JSON |
| `equipment.html` | HTML-таблица с информацией об оборудовании |
| `parse_html.py` | Парсинг HTML и сохранение данных в JSON |
| `parsed_equipment.json` | Данные, полученные в результате HTML-парсинга |
| `final_project.py` | Основной файл проекта: обработка оборудования, заявок и формирование отчёта |
| `report.txt` | Сформированный отчёт по заявкам |
| `schema.sql` | SQL-схема базы данных |
| `init_db.py` | Создание и инициализация базы данных |
| `check_db.py` | Проверка структуры базы данных |
| `task8_queries.py` | SQL-запросы для анализа оборудования и заявок |
| `equipment.db` | SQLite-база данных проекта |

## Выполненные задания

### Tasks 1–4
- Создание моделей и классов оборудования.
- Реализация заявок на техническое обслуживание.
- Разработка логики управления заявками.
- Работа с JSON-файлами.

### Task 5 — HTML Parsing
- Создан HTML-файл с таблицей оборудования.
- Реализован парсер с использованием `HTMLParser`.
- Полученные данные сохраняются в `parsed_equipment.json`.

### Task 6 — Final Project
- Реализована обработка оборудования и заявок.
- Добавлена фильтрация заявок по приоритету и статусу.
- Реализовано формирование отчёта `report.txt`.

### Task 7 — Database Design
- Создана SQLite-база данных.
- Разработаны таблицы `equipment` и `maintenance_request`.
- Добавлены первичные и внешние ключи.
- Настроены ограничения целостности данных.

### Task 8 — SQL Queries
Реализованы SQL-запросы для:
- Вывода заявок по приоритету.
- Подсчёта количества заявок по статусам.
- Поиска оборудования без активных заявок.
- Определения наиболее проблемного оборудования.
